### The premise

Every codebase has a graveyard. The PR closed with "let's not," the RFC that died in
review, the 2 AM group-chat idea that made everyone laugh and then everyone forgot.
OpenToxic is where those go instead of dying. We dig them back up, give them a repo,
and ship them — spec be damned, roadmap be damned, sometimes taste be damned.

We are not chasing "best practice." Best practice is what the last idea looked like
right before it got boring. We are chasing the idea that makes a senior engineer
go quiet for a second and say "...huh, okay, actually."

### Toxicity levels

```
┌──────────┬──────────────────────────────────────────────────────────┐
│  LEVEL 1 │ Unnecessary. Clever. Nobody asked, we built it anyway.    │
│  LEVEL 2 │ Architecturally deranged. Works better than it should.   │
│  LEVEL 3 │ A joke that got out of hand and now has production users.│
│  LEVEL 4 │ We ourselves are no longer sure if this is satire.       │
└──────────┴──────────────────────────────────────────────────────────┘
```

Every repo gets labeled honestly. If it's a bit, we say it's a bit. If it quietly
became load-bearing infrastructure for somebody's side project, we say that too,
usually with visible discomfort.

### Standing orders

- **Ship the weird version.** The safe version already exists somewhere, made by
  people paid more than us to make it boring.
- **No gatekept commits.** A bad first PR is a rite of passage, not a rejection.
- **Write the README straight even when the idea is not.** Chaos in the code,
  clarity in the docs — that's the whole deal.
- **"Toxic" describes the ideas, not the people.** Corrosive to convention, not
  to each other. Bring the chaos, leave the cruelty at the door.

### What you'll actually find in here

A rotating stockpile of tools, protocols nobody commissioned, abstractions that
should not exist and yet measurably improve on the ones that do, and the
occasional repo that started as a dare and ended up in somebody's production
stack without their manager ever finding out how it got there.

```diff
- "this violates at least four design principles"
+ "yes, and it's twice as fast"
```

### Getting involved

Open a PR. Open an issue. Open a discussion just to argue that one of our ideas
is bad — we will probably agree, and ship it anyway. If you've got a toxic idea
that needs a lab to grow in, this is the lab.
